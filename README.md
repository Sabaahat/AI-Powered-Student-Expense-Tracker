</p>📌 About the Project

The AI-Powered Student Expense Tracker is a Python-based application designed to help students manage their pocket money and daily expenses efficiently.

It allows students to record expenses, monitor their budgets, understand spending patterns, and receive AI-powered financial suggestions.

The main goal is to encourage students to develop better money-management and saving habits.

✨ Key Features

- 💰 Pocket Money Management – Record and monitor monthly pocket money.
- 📝 Expense Tracking – Add, edit, delete, and view daily expenses.
- 📊 Expense Analysis – Understand spending through charts and reports.
- 📅 Expense History – View previous transactions.
- 🎯 Budget Monitoring – Track spending against weekly and monthly budgets.
- ⚠️ Budget Alerts – Get alerts when spending approaches the budget limit.
- 🤖 AI-Powered Suggestions – Receive personalized spending and saving recommendations using Google Gemini AI.
- 🔮 Spending Prediction – Estimate future expenses based on spending history.

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/Sabaahat/Student-Expense-Tracker.git

2. Open the project folder

cd Student-Expense-Tracker

3. Create a virtual environment

python -m venv venv

4. Activate the environment (Windows)

venv\Scripts\activate

5. Install dependencies

pip install -r requirements.txt

6. Configure your Gemini API key

Create a ".env" file in the project folder:

GEMINI_API_KEY=your_api_key_here
GEMINI_MODEL=your_available_gemini_model

Keep your API key private. Never upload the ".env" file to GitHub.

7. Run the application

streamlit run app.py

🤖 AI Integration

Google Gemini AI is used to provide intelligent financial insights based on students' expense records.

The AI component aims to:

- Analyze spending behaviour.
- Identify unnecessary expenses.
- Suggest ways to save money.
- Provide personalized budgeting recommendations.

🎯 Project Objective

To develop a simple and intelligent expense-management system that helps students understand where their money goes and make smarter financial decisions.
